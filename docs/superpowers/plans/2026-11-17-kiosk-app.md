# Программа-киоск и заставка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exe для Windows, который держит `kiosk.339933.net` на весь экран, выходит только по PIN, после простоя крутит видео из Jellyfin; плюс скрипты блокировки Windows, работающие на любой редакции.

**Architecture:** Electron-приложение в `app/` (отдельный `package.json`). Вся логика — чистые модули с внедрёнными зависимостями (тестируются Vitest на macOS); тонкий слой `main.ts` связывает их с Electron API. Три окна: основное (удалённый сайт), заставка (локальная страница, видео из Jellyfin), сервис (локальная страница: PIN-пад и меню). Блокировка Windows — PowerShell-скрипты в `deploy/windows/` через реестр.

**Tech Stack:** Electron (актуальная стабильная на момент установки, ≥ 33), electron-builder (NSIS x64), TypeScript 5.6, zod 3.23, Vitest 2.1; PowerShell 5.1 (встроен в Windows 10/11).

**Spec:** `docs/superpowers/specs/2026-11-17-kiosk-app-admin-design.md` (части «1. Программа-киоск», «2. Заставка»). Файл `screensaver.json` и его схема — план `2026-11-17-kiosk-admin.md`, Task 1.

## Global Constraints

- Разрешённые хосты навигации: ровно `kiosk.339933.net` и `emailer.339933.net` (только https); путь `/admin` на `kiosk.339933.net` запрещён. Новые окна запрещены всегда.
- Стартовый URL: `https://kiosk.339933.net/`.
- Жест выхода: 5 касаний в зоне 100×100 px от левого верхнего угла за 3000 мс.
- PIN: 4–8 цифр, хранится scrypt-хэшем с солью; 5 неверных подряд → жест заблокирован на 5 мин.
- Заставка: порог из `screensaver.json.idleMinutes` (по умолчанию 3), проверка простоя раз в 5 с; без звука, если `muted`.
- Ключ API Jellyfin нигде не используется: вход пользователем «kiosk» (логин + пароль из локального конфига).
- Jellyfin: внутренний адрес первым (таймаут проверки 3 с), внешний — запасной.
- Локальный конфиг: `%ProgramData%\MaximaKiosk\config.json`; флаг намеренного выхода: `%ProgramData%\MaximaKiosk\service-exit`.
- Только механизмы, доступные на Windows 10/11 Home/Pro/Enterprise: реестр, планировщик задач, `powercfg`. Без Assigned Access / Shell Launcher / Keyboard Filter / gpedit.
- Коммиты — короткое русское описание, без AI.

## Review Focus

1. Плейлист Jellyfin содержит не только видео (фото, аудио) или элемент удалён — заставка пропускает его и не зависает на чёрном экране. Тест: Task 4 «нерабочий элемент пропускается», «все элементы нерабочие → заставка не включается».
2. Касание во время появления заставки (гонка «простой наступил — палец уже на экране») — заставка не остаётся висеть поверх активной работы. Тест: Task 3 «активность сразу после включения закрывает заставку».
3. Сеть до `kiosk.339933.net` пропала при старте Windows — не белый экран и не страница ошибки Chromium. Тест: Task 2 «ошибка загрузки → своя страница „Подключаемся…“ и повтор».
4. Крупное обновление Windows сбросило реестр — киоск должен это показать. Тест: Task 6 `checkProtections` по фейковому `reg query`.
5. Вертикальное видео 608×1080 — без чёрных полос и без растягивания основного кадра. Проверка: ручная, Task 4 Step 6.

### Task 4: Jellyfin-клиент и плеер заставки

**Files:**
- Create: `app/src/jellyfin.ts`, `app/src/playlist.ts`, `app/pages/screensaver.html`, `app/src/screensaver-page.ts`, `app/src/preload-screensaver.ts`

**Interfaces:**
- Produces:
  ```ts
  interface VideoItem { id: string; name: string }
  class JellyfinClient {
    constructor(o: { internalUrl: string; externalUrl?: string; user: string; password: string; fetch: typeof fetch })
    resolveBase(): Promise<string>        // GET /System/Info/Public с таймаутом 3 с: internal, иначе external, иначе throw
    login(): Promise<void>                 // POST /Users/AuthenticateByName → AccessToken, User.Id; заголовок
                                           // Authorization: MediaBrowser Client="MaximaKiosk", Device="Kiosk", DeviceId="<стабильный>", Version="<версия>"
    expand(itemIds: string[]): Promise<VideoItem[]>
    // по каждому id: GET /Items?ids=<id>&userId=… → Type; Playlist → /Playlists/<id>/Items?userId=…;
    // Folder|CollectionFolder|BoxSet → /Items?ParentId=<id>&Recursive=true&IncludeItemTypes=Movie,Video,Episode&SortBy=SortName&userId=…;
    // Movie|Video|Episode → сам; прочие типы пропускаются. Порядок: как в sources, внутри — как вернул Jellyfin.
    streamUrl(itemId: string): string      // `${base}/Videos/${id}/stream?static=true&ApiKey=${token}`
  }
  createPlaylistCursor(items: VideoItem[]): { next(): VideoItem | null; markBroken(id: string): void }
  // по кругу; сломанные пропускаются; все сломаны → next() = null
  ```
- 401 на любом запросе → один повторный `login()`.
- Страница заставки: два `<video>`: основной `object-fit: contain`, фоновый — тот же источник, `object-fit: cover`, `filter: blur(40px) brightness(.6)`, синхронно стартует; `muted` из настроек; `ended` → `next()`; `error` или нет `canplay` за 15 с → `markBroken` + `next()`; `next() === null` → `ipc 'screensaver:dismiss'`.

  3. `reg load HKU\KioskHive …\NTUSER.DAT` → `Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell = ExePath`; `Software\Microsoft\Windows\CurrentVersion\Policies\System`: `DisableTaskMgr=1`, `DisableLockWorkstation=1`, `DisableChangePassword=1`; `Software\Microsoft\Windows\CurrentVersion\PushNotifications\ToastEnabled=0` → `reg unload`.

HKLM: `SOFTWARE\Policies\Microsoft\Windows\EdgeUI\AllowEdgeSwipe=0`; `SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\HideFastUserSwitching=1`; автовход `SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon`: `AutoAdminLogon=1`, `DefaultUserName=Kiosk`, `DefaultPassword=<пароль>`, `DefaultDomainName=<COMPUTERNAME>`.
  5. Питание: `powercfg /change monitor-timeout-ac 0`, `standby-timeout-ac 0`, `hibernate-timeout-ac 0`.
  6. Задача планировщика `MaximaKioskWatchdog`: при входе пользователя Kiosk, `powershell -WindowStyle Hidden -File watchdog.ps1 -ExePath …`.

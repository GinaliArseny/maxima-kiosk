# Обновление киоска до 0.1.5

Это обычный MaximaKiosk, обновление опубликованной 0.1.3. Вариант MaximaKioskTest 0.1.4 не выпускался и не используется.

1. Пять касаний в левом верхнем углу → PIN → «Выйти на рабочий стол».
2. Запустить `MaximaKiosk-Setup-0.1.5.exe` поверх установленной 0.1.3. Удалять её не нужно.
3. Пуск → Киоск «Максима». PIN, доступ к Jellyfin и профиль браузера остаются прежними.
4. Пять касаний → PIN → **Проверить заставку**.
5. Видео запускается без ожидания простоя. Касание возвращает в отчёт. Если видео не запустилось, отчёт объясняет этап и ошибку.
6. Сфотографируйте отчёт при ошибке. Пароли и ссылки с токенами в отчёт не выводятся.

Тест работает и при выключенном автозапуске заставки; для обычного показа включите её в веб-админке.
Тест ограничен двумя минутами. Во время подготовки можно нажать «Отменить проверку».
Настройки и список источников берутся из веб-админки; доступ к Jellyfin — из локальных настроек EXE.
После сетевого сбоя автозапуск повторяет попытку раз в минуту без необходимости касаться экрана.

Админка: https://kiosk.339933.net/admin/
В меню обслуживания есть «Заставка: Jellyfin» для изменения адресов и учётных данных.
Автозапуск Windows и установочные скрипты не добавляются.
Аварийный выход на обычном ПК: Ctrl+Alt+Shift+Q.

Технически: сохранены appId `ru.maxima.kiosk`, package name `maxima-kiosk-app`, каталог `C:\Program Files\MaximaKiosk` и настройки `C:\ProgramData\MaximaKiosk`.
Windows CI устанавливает настоящий релиз 0.1.3, обновляет его, проверяет хэш файла настроек, переустановку поверх запущенного приложения и аварийный выход. Затем установленный EXE проходит тест меню PIN, сетевых ошибок, реального воспроизведения локального WebM и возврата к отчёту. Ответы Jellyfin в CI тестовые; доступ к серверу клиники и конкретные кодеки проверяются на киоске.

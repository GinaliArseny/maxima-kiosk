# Настройка компьютера киоска (Windows)

Киоск — обычный ПК на Windows 10/11 (любая редакция: Home, Pro, Enterprise) с сенсорным монитором 1920×1080 (ландшафт). На нём работает **программа-киоск «MaximaKiosk»**: сайт стенда на весь экран, выход только по PIN, заставка из Jellyfin по простою.

Настройка — с USB-клавиатурой или по удалённому доступу. Скрипты — в `deploy/windows/`.

## 0. Что нужно заранее

- Отдельная учётка **администратора** Windows для обслуживания (не «Киоск»). Скрипт без неё не запустится.
- Файлы — со страницы релизов https://github.com/GinaliArseny/maxima-kiosk/releases (последний `app-v…`): `MaximaKiosk-Setup-<версия>.exe` и архив `KioskSetup-scripts.zip` (`install-kiosk.ps1`, `uninstall-kiosk.ps1`, `watchdog.ps1`, эта инструкция). Всё в одну папку, например `C:\KioskSetup`.
- Jellyfin: пользователь **kiosk** с доступом **только** к библиотеке заставки; плейлист «Заставка киоска», которому открыт доступ пользователю kiosk. Ключ API Jellyfin на киоске не нужен (он даёт права администратора сервера).

## 1. Установить программу

Под администратором запустить `MaximaKiosk-Setup-<версия>.exe`. Программа ставится в `C:\Program Files\MaximaKiosk\`.

## 2. Учётка «Киоск» и первый вход

1. Под администратором: `powershell -ExecutionPolicy Bypass -File C:\KioskSetup\install-kiosk.ps1`. Если учётки `Kiosk` нет, скрипт создаст её (спросит пароль) и попросит **войти под ней один раз** — профиль Windows создаётся при первом входе.
2. Войти под `Kiosk`, дождаться рабочего стола, выйти.
3. Снова под администратором запустить `install-kiosk.ps1`. Каждый шаг печатает «✓ …». Скрипт:
   - ставит программу вместо рабочего стола для учётки `Kiosk`;
   - выключает свайпы от краёв экрана, диспетчер задач, блокировку и смену пользователя в `Ctrl+Alt+Del`, уведомления;
   - включает автовход под `Kiosk`;
   - запрещает сон экрана и компьютера;
   - даёт учётке `Kiosk` запись в `C:\ProgramData\MaximaKiosk` (настройки программы);
   - регистрирует сторож `MaximaKioskWatchdog`: упала программа — через ~10 с она снова на экране.
4. Перезагрузить. Компьютер сам войдёт под `Kiosk`, на экране — стенд.

Скрипт можно запускать сколько угодно раз — например, если после крупного обновления Windows в «Состоянии защиты» что-то стало ✗.

## 3. Первый запуск программы

1. **PIN.** 5 быстрых касаний в левом верхнем углу экрана (квадрат ~100×100 px, за 3 секунды) → «Задайте PIN» (4–8 цифр, дважды).
2. **Jellyfin** (нужна клавиатура). Меню → «Заставка: Jellyfin»: внутренний адрес `http://192.168.100.100:8096`, внешний (запасной) `https://videocrab.ru`, пользователь `kiosk`, его пароль → «Сохранить». Пароль хранится только на этом компьютере.
3. **Игра.** Меню → «Войти в игру заново» → ввести пароль игры. Игра запомнит устройство примерно на год.
4. **Заставка** включается в админке (`kiosk.339933.net/admin/` → «Заставка»): ссылка на плейлист, через сколько минут простоя, звук.

## 4. Обслуживание

5 касаний в левом верхнем углу → PIN → меню:

| Пункт | Что делает |
|---|---|
| Перезапустить киоск | Перезапуск программы |
| Войти в игру заново | Открывает форму пароля игры (если игра «забыла» устройство) |
| Сменить PIN | — |
| Заставка: Jellyfin | Адреса и пользователь Jellyfin |
| Состояние защиты | Какие настройки Windows действуют (✓/✗) |
| Выйти на рабочий стол | Закрыть программу и открыть Проводник; сторож не мешает до следующего входа/перезагрузки |
| Выключить компьютер | — |

5 неверных PIN подряд — жест не работает 5 минут. Меню само закрывается через минуту без касаний.

## 4а. Аварийный выход

**Комбинация `Ctrl+Alt+Shift+Q`** (нужна клавиатура) работает из любого окна программы, в том числе поверх заставки:

- **на обычном компьютере** (программу просто установили, `install-kiosk.ps1` не запускали) — закрывает программу сразу, без PIN. Для проверки программы на своём ПК;
- **на киоске** (программа вместо рабочего стола) — открывает окно PIN, как жест в углу. Посетитель с USB-клавиатурой стенд не закроет.

**Если программа не отвечает или PIN забыт:**

1. `Ctrl+Alt+Del` → «Выйти». Это сочетание обрабатывает Windows, программа его не перехватывает. Автовход срабатывает только при включении компьютера, поэтому после выхода откроется обычный экран входа — войти под администратором.
2. Не помогло — перезагрузить (кнопка питания в правом нижнем углу экрана `Ctrl+Alt+Del` или кнопка на корпусе) и **держать `Shift`**, пока Windows загружается: автовход не сработает, откроется экран входа.
3. Под администратором:
   - забыт только PIN — удалить файл `C:\ProgramData\MaximaKiosk\config.json` и перезагрузить. Программа попросит задать новый PIN; настройки Jellyfin (меню → «Заставка: Jellyfin») ввести заново;
   - нужно убрать киоск совсем — `uninstall-kiosk.ps1` (раздел 6).

**На своём компьютере, без `install-kiosk.ps1`:** «Диспетчер задач» из `Ctrl+Alt+Del` откроется *под* окном киоска и не поможет. Выходить комбинацией, жестом в углу или через `Ctrl+Alt+Del` → «Выйти» / «Перезагрузка». В автозапуск установщик программу не прописывает — после перезагрузки она сама не откроется.

## 5. Проверка после установки (чек-лист)

- [ ] После перезагрузки — сразу стенд, без рабочего стола и панели задач.
- [ ] Свайп от каждого края экрана ничего не открывает.
- [ ] `Ctrl+Alt+Del` (с клавиатуры): нет «Диспетчера задач», «Заблокировать», «Сменить пользователя».
- [ ] 5 касаний в углу → PIN; неверный PIN не пускает.
- [ ] `Ctrl+Alt+Shift+Q` (с клавиатуры) → окно PIN, программа не закрылась.
- [ ] `Ctrl+Alt+Del` → «Выйти» → экран входа Windows (а не снова киоск); войти под администратором можно.
- [ ] Меню → «Состояние защиты»: все ✓.
- [ ] Через N минут простоя — заставка; касание — главная стенда (касание не открывает плитку под заставкой).
- [ ] Игра открывается с главной и возвращается на стенд.
- [ ] Меню → «Выйти на рабочий стол» → Проводник; через минуту программа сама не вернулась.

## 6. Откат

Под администратором: `powershell -ExecutionPolicy Bypass -File C:\KioskSetup\uninstall-kiosk.ps1` → перезагрузка. Обычный вход в Windows, автовход выключен, пароль `Kiosk` из реестра удалён, сторож снят. Учётка `Kiosk` и программа остаются (удалить вручную при необходимости).

## 7. Ограничения

- На Windows Home часть запретов может не действовать. Тогда работает первый слой: программа сама возвращает себя поверх, если её что-то перекрыло.
- Пароль автовхода хранится в реестре открытым текстом (так устроен автовход Windows). Поэтому учётка `Kiosk` — без прав администратора, и пароль у неё свой, ни с чем не совпадающий.
- Обновление программы — вручную: «Выйти на рабочий стол» → установить новую версию от администратора поверх старой → перезагрузить. Сайт и данные обновляются с сервера без переустановки.
- Версии до 0.1.2 включительно поверх не обновляются (установщик принимал свой деинсталлятор за запущенную программу). Один раз: «Параметры» → «Приложения» → MaximaKiosk → «Удалить», затем поставить новую. PIN и настройки сохранятся — они в `C:\ProgramData\MaximaKiosk`.

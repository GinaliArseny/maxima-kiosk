# Настройка компьютера киоска (Windows)

Киоск — обычный ПК на Windows с сенсорным монитором. Сайт открывается в Google Chrome в kiosk-режиме при входе в систему.

## 1. Chrome

Установить Google Chrome (обычный, не Canary). Автообновление не отключать — сайт рассчитан на актуальный Chrome, но pdf.js собран в legacy-режиме и переживёт и старые версии.

## 2. Отдельный постоянный профиль

Профиль нужен постоянный (не инкогнито, без «удалять cookies при выходе»): в нём живут офлайн-кэш сайта и, позже, cookie игры.

Создать папку `C:\Kiosk\chrome-profile`.

## 3. Ярлык автозапуска

`Win+R` → `shell:startup` → создать ярлык с объектом:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --user-data-dir="C:\Kiosk\chrome-profile" --noerrdialogs --disable-pinch --overscroll-history-navigation=0 --disable-features=TranslateUI --disable-session-crashed-bubble --no-first-run --autoplay-policy=no-user-gesture-required https://kiosk.339933.net/
```

- `--kiosk` — полный экран без адресной строки и вкладок;
- `--disable-pinch`, `--overscroll-history-navigation=0` — нельзя увеличить страницу двумя пальцами и «смахнуть» назад;
- `--disable-session-crashed-bubble` — после выключения питания не будет плашки «восстановить вкладки».

Выход из kiosk-режима для обслуживания: `Alt+F4` с подключённой клавиатурой.

## 4. Windows

- Автовход в учётную запись киоска (`netplwiz` → снять «Требовать ввод имени пользователя и пароля»).
- Электропитание: «Отключать дисплей» и «Спящий режим» — **Никогда** (или по расписанию работы клиники через Планировщик заданий).
- Уведомления Windows и Центр обновлений — перенести активные часы на время работы клиники, чтобы перезагрузки шли ночью.
- Сенсорная клавиатура: отключить автопоявление (полей ввода на сайте нет).

## 5. Ориентация экрана

Сайт работает и в портрете (1080×1920), и в ландшафте (1920×1080). Ориентацию задаёт Windows: «Параметры → Дисплей → Ориентация».

## 6. Игра «Планета Зуб»

Плитка игры появляется, только когда в `public/data/clinic.json` задан `gameUrl`. Включать **после**:

1. игра опубликована и в ней есть кнопка/таймаут возврата на `https://kiosk.339933.net/`;
2. пароль игры один раз введён **на самом киоске** (в этом профиле Chrome) — cookie запомнит устройство.

Иначе ребёнок останется на заставке игры или увидит форму пароля.

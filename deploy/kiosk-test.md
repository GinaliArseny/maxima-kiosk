# Максима Киоск — Тест 0.1.4

Отдельная установка для тестирования при сломанном удалении старого MaximaKiosk.
Старую версию удалять не нужно. Перед запуском тестовой программы закройте старую.

1. Установить `MaximaKioskTest-Setup-0.1.4.exe`.
2. Пуск → **Максима Киоск — Тест**. Автозапуска нет, PowerShell-скрипты не нужны.
3. Пять касаний в левом верхнем углу за 3 секунды → задать PIN → меню обслуживания.
4. Проверить «Выйти на рабочий стол». Аварийная комбинация на обычном ПК: Ctrl+Alt+Shift+Q.
5. Запустить снова и проверить документы, игру и заставку.

Jellyfin: меню обслуживания → «Заставка: Jellyfin» → адреса сервера, пользователь и пароль.
Источники видео и время простоя — https://kiosk.339933.net/admin/ → «Заставка».
Вход в игру выполняется заново. Исправления веб-игры распространяются отдельно от EXE.

Идентификатор установки: `ru.maxima.kiosk.test`.
Программа: `C:\Program Files\MaximaKioskTest\MaximaKioskTest.exe`.
Профиль, PIN и настройки: `%APPDATA%\MaximaKioskTest` текущего пользователя.
Старые `ProgramData\MaximaKiosk` и профиль старого приложения не используются.
Удаление: Параметры Windows → Приложения → **MaximaKioskTest**.

Скрипты `deploy/windows` относятся к прежней установке и для тестовой версии не применяются.
